# Project working rules

Work inside this repository. Keep capture restricted to the public ksearch version, embedded catalog search and card detail forms. Invoke subprocesses without a shell. Keep evaluation pure, preserve baseline files and use synthetic data for fault injection. Use installed tools only for explicitly authorized live capture.

Run format, typecheck, tests, build and the isolated installation smoke before handing off. Update both README files and the relevant CLI documentation for public behavior changes. Label minimized observations and generated fixtures accurately; raw local recordings stay ignored. No credentials are required.

Commit, push, remote repository creation, CI dispatch, feedback submission, tagging, release and npm publication require authorization for that operation. Never use a wallet or paid endpoint to test discovery. Keep task-one repositories and evidence untouched.
